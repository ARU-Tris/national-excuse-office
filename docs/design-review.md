# M0 디자인 검토

2026-10-15. 설명서 13장 및 14장 3항에 따른 사용자 승인 완료. 사용자가 "Approve A and continue"로 A안과 현재 관인·PDF·포털 디자인, 기능 구현 및 공개 배포를 승인했다.

검토 주소: 개발 서버의 `#/design`.

- 로고 콘셉트 A/B/C, A 권장
- 심벌 6개 응용과 가로형·세로형 로고
- 3×3 한글 사각 관인, 25mm 벡터 인영
- F-05 내부결재서, F-06 불승인 처리결과 통지서, F-07 승인 결정통지서
- 홈, 신청, 결과, 문서 미리보기 화면

PDF는 React PDF로 직접 생성한 검색 가능한 벡터 텍스트다. 한글 폰트를 내장한다. Poppler 렌더링으로 정렬, 인장, 배경, 페이지 번호와 창작문서 표기를 확인한다. 물리적 인쇄 검증은 수행하지 않았다.

소스의 원본 설명서는 보존했다. 디자인 기준을 보존하며 전체 기능 구현과 9종 서식 검증을 진행한다. 실제 물리적 인쇄는 사용자 확인 항목이다.
