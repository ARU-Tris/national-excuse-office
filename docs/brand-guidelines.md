# 국립핑계관리청 브랜드 사용 규칙

버전 brand/1.0 · 제안일 2026-10-15 · A안 사용자 승인 완료

## 세 가지 콘셉트

- A 유예문장: 직립한 문서의 기하학과 비어 있는 결재칸. 권장안이며 현재 시안에 적용했다.
- B 사유의 질서: 네 단계의 접수·검토·결재·발급을 사각 질서로 조형했다.
- C 심사 인장: 문서 프레임과 추상 선을 통합했다.

실제 정부 표장, 실존 기관 CI, 스캔 관인, 캐릭터 이미지를 사용하지 않았다. 모든 심벌은 자체 작성한 SVG path다.

## 원본 및 응용

`public/brand`에 가로형, 세로형, 심벌, 단색, 역상, 워터마크, favicon, 사각 관인을 보관한다. 로고타입과 관인 글자는 배포 허용된 Nanum Gothic Bold의 윤곽을 변환했다. 폰트 저작권과 SIL OFL은 `public/fonts`에 포함한다. `npm run brand`가 원본 생성 스크립트다. PDF와 SVG는 `src/brand/artwork.json`의 동일한 path를 공유한다.

최소 보호 공간은 심벌 폭의 12%다. 웹 심벌은 24px 이상, 가로형은 150px 이상, 인쇄 심벌은 8mm 이상을 권장한다. 16px favicon은 심벌 단독으로 사용한다. 가로세로 비율 변경, 임의 회전, 그림자, 다른 색 조합, 글자 재배열을 금지한다.

웹 기본색: Navy #193A59, Blue #2A6191, Pale #EAF1F6, 본문 #18232D, 보조 #566572, 구획 #D3DBE2, 배경 #F4F6F8. 웹 토큰은 `src/styles/tokens.css`, PDF 토큰은 `src/documents/tokens.ts`가 관리한다.

## 관인

`국립핑계관리청장인` 아홉 자를 3×3으로 조형했다. 자형을 각 칸에 맞추어 확대·압축하고 고정된 미세 절개와 비대칭 외곽 인영을 추가했다. 이미지나 일반 텍스트 박스를 사용하지 않는다. 기본 인쇄 크기는 25mm 정사각형, 색상은 #AE333A다. 기관장 발신명의 오른쪽에 붙여 배치한다. 신청서·접수증·내부결재에는 기관장 관인을 사용하지 않는다.

워터마크는 심벌을 110mm 폭과 3.5% 불투명도로 본문 뒤에 넣는다. 내부문서는 약하게 조정한다. 최종 물리적 컬러·흑백 인쇄 품질은 실제 A4 출력으로 확인해야 한다.
