# 문서 엔진과 조판 기준

템플릿 버전 `forms/1.0`, 브랜드 `brand/1.0`, 심사 `review-engine/1.0`.

## 공통 데이터

접수번호, 접수일시, 신청사항은 사건 기록을 참조한다. 발급번호·발급일·해당 시점의 결정은 `DocumentRecord`에 저장한다. 이의신청의 원처분과 재심사 결과는 독립적으로 보존한다. 재발급은 심사 엔진을 다시 실행하지 않는다. 모든 화면 일자는 Asia/Seoul로 표시한다.

## 조판

A4 210×297mm, 위·좌우 20mm, 하단 본문 영역 27mm 확보. 본문 10.5pt, 명조 1.55 줄높이, 보조 정보 8.5pt, 기관명 20pt. 긴 텍스트를 축소하지 않고 다음 페이지로 넘긴다. 표의 짧은 메타데이터 행은 분할하지 않고, 1,000자 사유와 1,500자 소명은 분할 가능한 문단으로 처리한다. 신청서 서명은 별칭과 ‘전자 신청’ 표기다.

고정 푸터에 문서번호, 발급일, 접수번호, 담당부서, 서식 버전, 페이지 번호, 창작문서 표시를 둔다. 관인은 25mm, 워터마크는 110mm/3.5%로 본문 뒤에 배치한다. 내부 검토 및 신청 서식에는 워터마크를 약하게 적용한다. 내부 문서에는 기관장 관인을 넣지 않고 가상 직위의 기안·검토·결재선을 사용한다.

## 글꼴

초기 나눔 서체에는 한자 글리프가 없어 전체 CJK를 포함하는 Noto 폰트로 PDF를 변경했다. 가변 폰트는 React PDF에서 직접 임베딩하지 않는다. `scripts/prepare-fonts.py`가 400/700의 정적 TTF를 생성하며, 배포된 파일은 정적 TTF다. 원본:

- https://github.com/google/fonts/tree/main/ofl/notosanskr
- https://github.com/google/fonts/tree/main/ofl/notoserifkr

원본 `NotoSansKR[wght].ttf`, `NotoSerifKR[wght].ttf`를 각각 `tmp/fonts/NotoSansKR-VF.ttf`, `tmp/fonts/NotoSerifKR-VF.ttf`로 준비한 뒤 fonttools가 있는 Python으로 스크립트를 실행한다. SIL OFL은 `public/fonts`에 포함한다. 한글·한자·영문·숫자·기본 특수문자의 추출 및 렌더링을 검증한다. 모든 유니코드 문자나 컬러 이모지에 대한 지원을 주장하지 않는다.

PDF 글꼴은 첫 발급 시 같은 사이트에서 불러오며 미리 가져오기 실패 시 빈 문서를 발급하지 않는다. PDF.js 미리보기와 다운로드는 동일한 생성 Blob을 사용한다. 인쇄 버튼은 그 PDF를 새 창에 열어 브라우저/PDF 뷰어의 실제 인쇄 기능으로 이어진다.
