## 자동화 결과

`npm test`: **20/20 통과**. 엄격 불승인, 짧은 유예 승인, 관대한 조건부 승인, 보완 최종 처분, 재심사 유지·변경, 기존 통지서 보존, 서울 날짜, 입력/임시작성 검증, 기록·백업·동시 심사·삭제 검증.

프로덕션 `npm run preview`의 `/national-excuse-office/` 경로에서 **10개 E2E 시나리오 통과** (전체 9개 실행 후 키보드 전용 시나리오 추가 실행, 최종 모바일 재확인):

1. 접수·동의·불승인·PDF 내려받기·새로고침·이의신청·ZIP·JSON·별도 브라우저 컨텍스트 복원
2. 기한 없음·10분·구체적 사유 승인 및 F-07
3. 보완요구 → 1회 보완 → 최종 처분 및 F-03 보존
4. 긴 한글/한자/영문/숫자 입력, PDF 페이지 추가, HTML 문자 비실행
5. 390px 모바일, 가로 넘침 없음, 미완성 신청서 임시저장 복원, 외부 요청 없음
6. 삭제 전 확인, 취소 보존, 손상된 백업 차단
7. IndexedDB 차단 안내 및 접수 지속
8. 글꼴 로딩 실패 시 빈 PDF 차단·한글 오류 안내·재시도 복구
9. 이미 로드한 신청·심사 코드를 네트워크 연결 없이 실행

10. 키보드 Tab/Space/Enter만으로 신청서 입력·필수 동의·접수 완료 확인

키보드 흐름은 별도 테스트로 통과했다. 실제 스크린리더 제품을 통한 음성 검증은 수행하지 않았다.
